	Titilus: the current understanding of virtualenv and github
	Venv:
		If sans the virtual environment, one operates python under single library while the python is a script heavily dependent on the different versions of python and their corresponding syntax, und syntax sugar and paradigm of coding. In order to achieve isolation, the concept virtual environment provides the namespace narrowing in the sense of kernel programming. It allows the project to remain in the boundary of appropriate packages and the version of python. 
	Github and git: 
		Github provides interface to manage your own account of repository and the worldwide decentralized services to peak into how others differ from your coding habits and what you can apprehend thence. Git is a free and open source version control tool developed mainly by Linus torvald and those we have to send sincere gratitude. It's a complicated program to maintain the patch and codebase while allowing control of divergence(branch) and convergence(merge). It is the different paradigm compared ot aye day's subversion, the centralized control of versions.
